# Solution Document Templates

Quick reference for the three solution tracks. Use these as starting points, not rigid forms — scale sections to the complexity of the learning.

## Minimal Bug Fix (< 5 lines)

```markdown
# <What broke>

**Track:** Bug | **Date:** YYYY-MM-DD | **Severity:** P2

**Symptom:** <one line>
**Root Cause:** <one line>
**Fix:** <one line>
**Prevention:** <one line>
```

## Minimal Knowledge (single pattern)

```markdown
# <Pattern name>

**Track:** Knowledge | **Date:** YYYY-MM-DD

**When:** <trigger condition>
**Do:** <the pattern>
**Don't:** <the anti-pattern>
```

## Minimal Decision (clear-cut choice)

```markdown
# <Decision>

**Track:** Decision | **Date:** YYYY-MM-DD | **Status:** Active

**Context:** <one line>
**Chose:** <option> **because** <one line rationale>
**Trade-off:** <one line accepted downside>
```

## Full Templates

See the main SKILL.md for full-length templates with all sections.
Use full templates when:
- Root cause was surprising or multi-layered (Bug track)
- Pattern has nuanced applicability rules (Knowledge track)
- Decision was contentious or had strong competing options (Decision track)
