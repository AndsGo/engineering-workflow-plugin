## 5. Calibration (tier distribution)

Over the held-out set: **T0 ×1, T1 ×2, T2 ×3** (S6 counted as T2). ≈17% / 33% / 50%.

Judgement: **sane mix** — not all-T2 (no ceremony-restoration) and not all-T0 (no under-classification). Caveat: the held-out set is small (6) and skewed toward substantial work because it is drawn from this repo's *feature* history; a real consumer's day-to-day (more typos, config edits, small fixes) would shift the mass toward T0/T1, which is the intended direction. The E-1 security overlay fired correctly and exclusively on the one security scenario in all 10 runs across both rounds — no false positives on non-security scenarios, no false negative on S6.

## 6. Live empirical (controller-observed)

The most real application available: **v1.4 dogfooded itself.** This whole feature was run through the framework as a work-item — classified **T2 + overlay** (rewrites the plugin's core contract; affects every consumer's routing), and it took the full flow: brainstorming → spec → writing-plans → **plan-review-personas (which returned RETHINK round 1, forcing a redesign)** → round-2 REVISE (hardening) → subagent-driven execution. During this eval step, the completion-time checkpoint (0.3 #6) is what re-scanned and caught the S5 rubric gap before "done"; and the eventual push is gated by floor #4 (no auto-irreversible), pending user confirmation at `finishing-a-development-branch`. The framework classified itself correctly as heavyweight and its own adversarial gate caught real blockers — the intended demonstration.

## 7. Anti-self-certification note

The classifiers were genuinely blind: each was a fresh Sonnet subagent whose entire prompt was the verbatim rubric + the 6 scenario descriptions + an instruction to use no files/tools and that no expected answers existed in its context. The expected tiers live only in this report and the plan/spec (which the classifiers could not read — they had no repo access). Ground truth was scored by the controller after collection. The gate is applied to the blind outputs above, not to a self-graded walkthrough.
